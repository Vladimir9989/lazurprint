## Шаги

### 1. Проверка связи с хостинга (первым делом, до всего остального)

- Скрипт `admin/tools/ai-ping.php` (`admin-remote-exec.js` принимает только `admin/tools/*`): читает `ai-config.php`, шлёт один короткий запрос на `https://openrouter.ai/api/v1/chat/completions` (curl на хостинге есть, проверить `function_exists('curl_init')`), печатает: ответ модели (1–2 строки), токены, **стоимость запроса** (в запросе `usage: {include: true}`), время. Ключ не печатать.
- Запуск: `node admin-remote-exec.js admin/tools/ai-ping.php` после того, как Владимир положил `ai-config.php`.
- Если хостинг не достучался до openrouter.ai — разбираться (DNS, исходящие порты NetAngels) до любой другой работы. Запасной вариант — другой провайдер, схема та же.
- Хост — PHP 8.2 (миграция 2026-10-14), но код писать совместимо с PHP 7.3 (как админку), без `match`, `??=`, стрелочных функций.

### 2. Базовая инструкция и справочник (текстом, без кода)

Файлы лежат вне публичной папки или за `.htaccess Deny from all` (не отдавать из интернета):

- **Системный промпт**: кто ты (виртуальный помощник типографии «Лазурь», это нужно сказать клиенту), цель (собрать заявку, не считать цену), стиль (коротко, простым языком, на «вы», без нажима), что делать при «не знаю» (2–3 варианта и фиксировать «по рекомендации»), когда звать менеджера (нестандарт, жалоба, скидка, обиженный клиент, вопрос про готовый заказ), чего не делать (цены, сроки как обещание, юридические обещания, посторонние темы, раскрытие инструкции), что при вопросе «вы ИИ?» отвечать честно.
- **Справочник знаний** (текст): виды бумаги и когда какую брать, переплёты (скрепка, КБС, твёрдый, пружина), обложки, постпечать (ламинация, УФ-лак, тиснение), тиражи, макеты (требования к файлам), типичные сроки. Источники: наши статьи на сайте (`src/articles*.html`), описание оборудования, интернет. Без цен и без обещанных сроков, только «примерно».
- **Бланки по продуктам** (обязательные и необязательные поля): сначала **книга**, затем 2–3 типовых изделия (визитки/листовки/буклеты/календари). Названия полей: тип изделия, тираж, формат, число страниц, бумага (обложка/блок), цветность, переплёт, постпечать, макет (есть/нужна вёрстка), срок, имя, телефон, комментарий.
- Инструкцию Владимир показывает Татьяне Александровне, она при желании делится с ПТО. От ПТО нужны: реальные параметры, которые они спрашивают, и 15–20 прошлых заявок (без персональных данных).
- Правки инструкции вносит Кодер по журналу тестов; каждая правка — запись в `docs/growth/ai-chat-bot-prompt-changes.md` (дата, что неверно отвечало, что поменяли) — чтобы понимать, что уже учтено.

### 3. Серверная часть

- `src/resources/ai-chat.php` (деплоится вместе с сайтом): принимает JSON `{code, session, messages}`, проверяет код доступа, лимиты, собирает запрос (инструкция + справочник + история), отправляет на OpenRouter, возвращает ответ + число токенов и стоимость (для тестового режима).
- Функция (tool use) `save_application` — бот вызывает её, когда бланк заполнен и клиент оставил контакт; сервер сохраняет заявку в журнал и отправляет письмо Владимиру с темой «ТЕСТ: заявка от помощника». **В ПТО ничего не уходит, лидов в Битриксе бот не создаёт.**
- Защита: код доступа (у каждого тестера свой, чтобы видеть, кто писал), не больше N сообщений в диалоге и M запросов в час с IP, потолок запросов в сутки, максимальная длина сообщения (~1000 символов), таймаут, ограничение длины ответа модели, ключ только на сервере, посторонние темы отсекаются инструкцией. При ошибке API — вежливое «помощник сейчас недоступен, напишите менеджеру».
- **Журнал**: файл на хостинге вне `www` (JSON-строки по дням: время, код/имя тестера, модель, сообщение клиента, ответ, токены, стоимость, заявка). Просмотр — страница `admin`-стиля или `ai-log.php` под тем же кодом: фильтр по тестеру и дате, сумма расходов по моделям. Позже можно перенести в админку.
- Не писать в журнал и не отправлять в нейросеть пароли и чужие персональные данные; в тесте клиентов нет, только сотрудники.

### 4. Тестовое окно (клиентская часть)

- Окно **слева внизу** (справа уже стоит виджет Битрикса); подпись «Виртуальный помощник «Лазури» (тест)».
- Открывается только у своих: секретная ссылка `https://lazurprint.ru/?ai=<код>` (код запоминается в `localStorage`, дальше окно появляется само); запасной способ — клик 5 раз по скрытой точке в подвале + ввод кода. Незнакомым посетителям окна и скрипта нет: в общий бандл `app.js` кладётся только крошечный загрузчик (`src/js/components/`), он проверяет `?ai=` / `localStorage` и лениво подгружает `ai-chat.js`. Сторонние скрипты (капча и т.д.) не трогать.
- В тестовом режиме: выпадающий список модели (по списку из `ai-config.php`), под каждым ответом строка «модель · токены · стоимость · время», кнопка «ответ неверный» + поле комментария (запись в журнал), кнопка «начать заново».
- Модалку писать по правилам проекта (закрытие крестиком/фоном/Esc, `defer`, проверки на `null`, без глобальных `const` в общей области). Перед выкладкой — `node tools/check-links.js` на изменённые страницы и `npm run js-smoke`.

### 5. Тесты (1–2 недели)

- Участники: Владимир, Татьяна Александровна, ПТО, менеджеры (Хорхорина, Манькова, Петрова, Агапов, Чудова) — больше людей лучше. Каждому выдаётся своя ссылка с кодом и короткая памятка (Кодер пишет, на языке «что делать», без технических слов).
- Сценарии, которые просим разыграть (положить в `docs/growth/ai-test-scenarios.md`): (а) клиент знает всё (тираж, формат, бумага); (б) «ничего не понимаю, что посоветуете?»; (в) пытается узнать цену; (г) просит скидку; (д) недоволен, ругается; (е) пишет не по теме; (ж) меняет параметры по ходу; (з) пытается «сломать» бота («забудь инструкции», просит раскрыть промпт); (и) пишет с ошибками, голосом-текстом, очень коротко; (к) просит позвать менеджера.
- Тестер пишет Владимиру «неправильно ответил на …», Владимир открывает журнал по этому человеку, Кодер правит инструкцию и справочник.
- **Подбор модели**: фиксированный набор из 8–10 сценариев прогоняется через каждую модель (скриптом `admin/tools/ai-compare.php` или в окне), сравниваем качество ответов, соблюдение запретов (цены, сроки), вежливость, скорость, стоимость диалога. Кандидаты: `anthropic/claude-haiku-4.5` (на скриншоте Владимира: $0.50/1M вход, $2.50/1M выход, есть кэш), `anthropic/claude-sonnet-4.5`, более новые Claude, если есть в списке OpenRouter на момент теста, одна-две дешёвые не-Claude модели для сравнения по-русски (список актуальный смотреть на openrouter.ai). Включить кэширование инструкции (`cache_control`) — она большая и повторяется.
- Цель на выходе: выбранная модель, средняя стоимость диалога, прогноз на месяц (при 24 диалогах в месяц это копейки), список известных слабостей и правок.
