## Решения Владимира

Заявка в тесте уходит только на почту Владимира с пометкой «ТЕСТ», не в ПТО.
- Движок — **собственный бот через API OpenRouter** (подписка Битрикса и подписка Владимира на Claude для этого не подходят: подписка привязана к компьютеру Владимира, API платится отдельно за расход). Переключатель модели (Haiku 4.5 / Sonnet 4.5 / др.) и показ расхода — только в тестовом режиме.
- Бюджет: Владимир предложил пополнить **около 3000 ₽** сразу, на пару месяцев без донесений (по оценке хватит с запасом; в сообщении Татьяне названо «от 1000 до 3000 ₽» на тест). Точные цифры узнаем после теста на разных моделях.
- Бот не называет цены: цену считает ПТО. Бот собирает параметры (тип, тираж, страницы, бумага, обложка, сроки, макет, контакты), при «не знаю» предлагает 2–3 варианта, зовёт менеджера при необходимости. **Лид бот не создаёт**: менеджер создаёт лид вручную (решение Владимира, чтобы не копились мусорные лиды); бот пишет в чат итоговую заявку.
