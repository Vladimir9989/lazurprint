## Общие правила для всех этапов

- Перед началом прочитать `CLAUDE.md` (разделы «Подключение JS на странице», «Важное», «Журнал дня») и `docs/claude/catalog-photos.md` (устройство карточек).
- **718 карточек руками не править.** Массовые правки HTML — одноразовым node-скриптом в scratchpad (регулярки по `<li class="catalog__item catalog-item"…>` / `<img …>`), затем `git diff --stat` и выборочный просмотр диффа. Скрипт в проект не класть.
- Не трогать данные карточек: названия, цены, артикулы, `data-city`, порядок. **Повторяющиеся артикулы (27 шт.) — так задумано**: бухгалтерия держит серию (например «Я люблю Реж») под одним артикулом. Не «исправлять», не сообщать как ошибку.
- Скрипты: `src/resources/catalog-suvenir.js` (вкладки, поиск, сортировка, город, «Хит продаж»), `catalog-pdf.js` (кнопки «Скачать PDF» по подгруппам), `catalog-cart.js` (корзина и Excel, сделана 2026-10-29). Все три должны работать после каждого этапа.
- Стили — `src/styles/_catalog-suvenir.scss` (блок `.catalog…`, `.catalog-item…`, в конце — корзина `.cart-…`). Брейкпоинты — миксины `xxl 1320 / xl 1024 / lg 896 / lm 786 / mg 676 / md 576 / sm 410` (все `max-width`). Цвета — `--color-primary #3E77FB`, акцент `#6de2eb`, заголовки `--color-galaxy #081f5c`, градиент `linear-gradient(135deg, #3E77FB, #6de2eb)`.
- `npm run dev`/`build` самому не запускать (см. CLAUDE.md). Компиляцию стилей проверять `npx gulp styles`, скрипты — `npx gulp scripts` не нужен (файлы из `src/resources/` копируются как есть). Для просмотра в браузере попросить Владимира включить свой `npm run dev` и смотреть через Playwright MCP на `http://localhost:3000/catalog-suvenir.html` (порт уточнить), иначе — после деплоя на lazurprint.ru.

## Этап 1. Скорость: ленивая загрузка фото (маленький, без видимых изменений)

**Статус (2026-10-29):** правки сделаны локально (733 фото с lazy, 6 первых без, preload убран; check-links и js-smoke ок). Ждёт проверки в браузере (нужен dev-сервер Владимира) и слова «деплой».

1. Всем `<img>` внутри `.catalog-item__img-cnt` и `.catalog-slider` добавить `loading="lazy" decoding="async"`. **Исключение:** первые 6 карточек первой секции (`data-tab="1"`) — без `lazy` (первый экран, иначе фото появятся с задержкой). Логотип и прочие картинки вне каталога не трогать.
2. `width`/`height` у фото **не добавлять**: контейнер `.catalog-item__img-cnt` уже держит квадрат (`aspect-ratio: 1`), карточки не «прыгают» (в аудите это было указано как проблема — ошибочно).
3. В `<head>` `catalog-suvenir.html` удалить строку `<link rel="preload" href="main.css" as="style">` — она без `?_v=`, браузер качает файл зря и пишет предупреждение. Проверить grep'ом, нет ли такой же строки на других страницах `src/*.html`; если есть — сообщить Владимиру списком, без правки (отдельная задача).
4. Проверить, что ленивые фото не ломают:
   - PDF: `catalog-pdf.js` грузит картинку заново по `img.src` через `new Image()` — с `lazy` это работает, но проверить PDF подгруппы, которую не прокручивали.
   - корзину: `catalog-cart.js` берёт `img.currentSrc || img.src` — у незагруженной lazy-картинки `currentSrc` пустой, `src` есть → ок; проверить добавление товара снизу страницы без прокрутки до фото (через поиск).
5. В `docs/claude/catalog-photos.md`, шаг 7 «Процесс добавления продукции», дописать: у `<img>` новой карточки — `loading="lazy" decoding="async"`.
6. Замер «после» тем же способом, что «до» (Playwright, `performance.getEntriesByType('resource')`, фото с `/images/img/rs/`). Ожидание: на первом экране ≤ 40 фото, ≤ 600 КБ.

## Этап 2. «Показать ещё» вместо простыни из 200 товаров (средний, JS)

Цель: в обычном режиме во вкладке видно **24 товара** (на ширине ≤ 676 px — **12**), под списком кнопка «Показать ещё (осталось N)», каждое нажатие добавляет ещё столько же.

Правила:
- Делать в `catalog-suvenir.js` (там вся логика фильтров), не отдельным файлом.
- Порция считается **по всей секции**, в порядке DOM, через все подгруппы (`.catalog__list` с заголовками `.catalog__subtitle` и кнопками PDF). Подгруппа, в которой не осталось видимых товаров, скрывается вместе с её заголовком и кнопкой PDF; частично видимая — показывается.
- Скрывать «лишние» карточки **отдельным классом** `catalog-item--more` (`display: none` в SCSS), **не** через `style.display`: фильтры (`filterProducts`, проверка `style.display` в строках про `hasVisibleItem`) опираются на инлайн-стиль, смешивать нельзя. Проверки «есть ли видимые» в фильтрах дополнить учётом нового класса.
- Порционный показ — **только без фильтров**. Если активен поиск, город или «Хит продаж» — показывать все совпадения, кнопку скрыть. При сбросе фильтров / переключении вкладки / смене сортировки — снова первая порция.
- Сортировка переставляет карточки — порцию пересчитывать после сортировки.
- Кнопка «Скачать PDF» должна выдавать **все** товары подгруппы, а не только показанные (проверить: `catalog-pdf.js` берёт `querySelectorAll('.catalog-item')` по списку — ок, но убедиться, что нет фильтра по видимости).
- Корзина: кнопки «В корзину» есть у всех карточек (`decorateItems` проходит по всем) — после «Показать ещё» они на месте.
- Старый пустой `.catalog__pagination` (скрывается в `cacheElements`) можно использовать как место для кнопки или удалить вместе с кодом — на выбор, но аккуратно.
- Стиль кнопки: по центру, `--color-primary` рамка 2px, при наведении заливка; на телефоне на всю ширину.
- `aria-live="polite"` у счётчика не обязателен; после «Показать ещё» фокус не переносить.

Проверить дополнительно: вкладка «Зонты» (3 товара) — кнопки нет; «Блокноты» — нажать «Показать ещё» до конца, кнопка исчезает; поиск во время раскрытого списка → сброс → снова 24.

## Этап 3. Сетка и карточка товара (средний, в основном CSS)

### Сетка
- Контейнеры каталога сейчас с инлайном `style="max-width: 1024px;"` (в `catalog-suvenir.html` 2–3 места: шапка-плашка, `catalog__content`) — заменить на класс `catalog__wrap` с `max-width: 1240px`.
- `.catalog__list`: **4 колонки** > 1024 px, **3** — ≤ 1024, **2** — ≤ 896 и **на телефоне тоже 2** (сейчас на ≤ 676 одна — убрать `grid-template-columns: repeat(1, 1fr)` у `mg`). `gap` 20px, на ≤ 576 — 10px.

### Карточка (`.catalog-item…`)
- Фон подложки фото — светло-серый `#f4f6fa`, фото внутри с отступом 12px (`padding` у `__img-cnt`, `object-fit: contain`), белый фон товара на сером смотрится «студийно». Скругление карточки 12px, рамка `1px solid #e8edf5`, тень мягче, при наведении — подъём (уже есть) + рамка `--color-primary`.
- Название: 14px, `#081f5c`, максимум 3 строки (`-webkit-line-clamp: 3`), полное — в `title` не нужно.
- **Цена — главная**: 20px, `font-weight: 700`, цвет `#081f5c` (не бледно-голубой). «Цена уточняется» и «от N шт…» — 14px, серым. Артикул — 12px `#9aa5b8`, под ценой отдельной строкой (сейчас справа в строку — на 2 колонках телефона не влезет).
- Блок корзины (`.cart-add`, создаётся в `catalog-cart.js`): кнопка «В корзину» — градиент бренда, скругление 8px; поле количества — сделать степпер **«− [1] +»** (две кнопки вокруг input, логика в `catalog-cart.js`: клампинг 1…999999, как сейчас). На ≤ 576 px: степпер и кнопка — в две строки, кнопка на всю ширину; текст кнопки на узких — иконка корзины + «В корзину».
- Бейдж «Хит продаж» оставить, на 2 колонках телефона уменьшить (9px уже есть на `md`).
- Проверить карточки без фото (`__img-cnt--placeholder`) и с мини-слайдером (футболки, `.catalog-slider`) — стрелки слайдера на 2 колонках не должны перекрывать фото целиком (при необходимости скрыть стрелки на ≤ 576, оставить точки).
