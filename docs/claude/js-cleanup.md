## Что сделано

- **Форма заявки работает на всех страницах.** Раньше капча «Я не робот» была подключена на 27 страницах из 218 — на остальных форма не отправлялась (П1); кнопка «Свяжитесь с нами» в подвале работала на ~61 странице (П2). Теперь форма и ленивая капча — в бандле (`src/js/components/form-modal.js`), кнопки открывают форму атрибутом `data-open-form`, 10 копий кода открытия формы удалены (П3). Ответы `mail.php` с ошибкой (он всегда отдаёт 200) больше не ведут на `thanks.html`, посетитель видит понятное сообщение.
- **news59–62:** не было `inputmask`/`just-validate` — форма уходила без проверки и без капчи. Причина — заготовка `tools/new-page.js`, исправлена.
- **Все скрипты страниц изолированы** (IIFE / `DOMContentLoaded`, проверки на `null`) — П4, П5. Глобальных объявлений нет ни в одном постраничном скрипте.
- **Swiper — одна версия 11.2.10, локально** (было: CDN v11 синхронно в `<body>` на 56 страницах + локальный v6.4.7 на 2, с перепутанными CSS/JS) — П6.
- **Единый порядок:** всё `defer` в `<head>`, пути относительные, лишние скрипты убраны по факту отсутствия их блоков. Было 863 `<script src>`, стало 793. Синхронных `<script src>` — 0, дублей — 0. Убраны: неиспользуемый `simplebar` (каталог сувениров), блокирующий `socials.js`, отладочные `console.log`.
- **Ошибки JS:** было 13+ страниц с ошибками в консоли, сейчас 0 (`npm run js-smoke -- --all`). Исправлены: падения `about.js` на страницах без видео, двойной inputmask в `articles13`, `new Swiper('.news__img-cnt')` на блоках без слайдера (5 страниц), `alt="undefined"` у увеличенного диплома на главной.
- **Инструменты:** `tools/js-smoke.js` (`npm run js-smoke`), `tools/js-form-test.js`, `tools/js-normalize.js`, обновлён `tools/js-inventory.js`. jsdom в зависимости проекта не входит: `npm i jsdom@24` в папку вне проекта и `JSDOM_DIR=<папка>`.
