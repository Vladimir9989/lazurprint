## Решения пользователя (2026-10-09) — выполнено

1. **`mail.php` проверяет, ушло ли письмо**: при ошибке почтового сервера — «Произошла ошибка» + причина в лог хостинга, посетитель видит «Не удалось отправить заявку».
2. **Лимит 5 заявок/час считает только ушедшие заявки** (прошли капчу и приняты почтой). Неудачные попытки лимит не тратят. Порядок проверок: ловушка → время → поля → лимит (только чтение) → капча → письмо → запись в лимит. Сбой связи с Google — «Произошла ошибка», а не «ВЫ РОБОТ».
3. **Упёршемуся в лимит** (на моё усмотрение): раз лимит теперь считает только ушедшие заявки, это живой человек, у которого уже 5 заявок дошли, — ответ «Слишком много заявок», в форме: «Вы уже отправили несколько заявок за последний час — мы их получили и свяжемся с вами. Если вопрос срочный, позвоните нам.»
4. **JSON-ответ — не делал** (на моё усмотрение): после п. 1–3 у каждого исхода свой текст, клиент считает успехом только пустой ответ — этого достаточно; список ответов — в шапке `mail.php`.
5. **Имя — до 50 символов.**
6. **Email — по желанию**: пустой проходит, заполненный проверяется по формату (и в браузере, и в `mail.php`); подсказка в поле «Ваш email (необязательно)»; в письме «Почта: не указана». Заодно: если email указан, «Ответить» в письме сразу на адрес клиента (`addReplyTo`).
7. **Счётчики на главной — один раз**, при первом появлении блока.
8. **Видео «Коротко о нас»** — оставлено продолжение с места паузы (на моё усмотрение: так ведут себя привычные плееры; закрыл случайно — досмотрит).
9. **Каталог сувениров — «Ничего не найдено»** с кнопкой «Сбросить поиск» (кнопка — только если причина в поиске; стили — `_catalog-suvenir.scss`, `.catalog__empty`).
10. **Архив фото `events.html`**: пароль и ссылка убраны из кода. Ссылка зашифрована паролем (AES-GCM, ключ PBKDF2 из пароля, встроенное шифрование браузера), расшифровывается только верным паролем; пароль прежний. Сменить пароль/ссылку — `node tools/archive-link.js "Пароль" "ссылка"`, вставить вывод в `ARCHIVE` в `events.js`. Работает только по https и на `localhost` (иначе понятное сообщение). Ограничения: старый пароль и ссылка остались в истории git; перебором пароль подобрать можно — но не прочитать из страницы.
11. **Форма Битрикс24 раз в сутки** — задумка пользователя, оставлено; добавлен только `try/catch` вокруг `localStorage` (в приватном режиме браузера раньше падал весь скрипт и форма не грузилась вовсе — теперь показывается). Варианты улучшения — в ответе пользователю, ждут решения.
12. Пустой `src/work.js` удалён (в git его не было).

## Решение по ES-модулям (2026-10-08)

Рассмотрено и **отложено как невыгодное** для этого сайта: собственный код маленький (на странице 10–20 КБ своего JS, бандл `app.js` — ~10 КБ), основной вес — библиотеки `inputmask` (124 КБ) и `swiper` (155 КБ), их модули не облегчат без перехода на сборщик (esbuild/rollup) вместо текущего gulp-конвейера. Изоляцию кода, ради которой модули обычно и берут, уже дали IIFE. Нативные `import` без сборщика добавят запросы-цепочки и сломают текущую минификацию. Возвращаться, только если сайт перейдёт на сборщик по другим причинам; тогда главный выигрыш — урезанный Swiper (только нужные модули).
