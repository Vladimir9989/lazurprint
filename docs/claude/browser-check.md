# Проверка сайта в браузере — общий чек-лист

Один список для проверки руками после чистки скриптов, аудита JS и решений по форме (всё — 2026-10-08). Объединяет инструкции из [`js-cleanup.md`](js-cleanup.md) и [`js-audit.md`](js-audit.md). Галочки `[x]` можно ставить прямо в этом файле.

**Подготовка.** Запустить свой `npm run dev`, открыть сайт (обычно `http://localhost:3000` — именно `localhost`, не IP-адрес, иначе не откроется архив фото в п. 10). На каждой странице — **Ctrl+F5** (сброс кэша) и **F12 → Console**. Любая красная ошибка в Console = проблема: прислать название страницы и текст ошибки.

## Это проверено автоматически — можно не смотреть

На всех 221 странице (jsdom): нет ошибок JS; каждая кнопка заявки открывает форму, капча подгружается ровно один раз; число запущенных слайдеров совпадает с исходным. Форма — 29 сценариев: нет галочки, капча не загрузилась, «ВЫ РОБОТ», сбой сервера, обрыв связи, лимит заявок, двойное нажатие «Отправить», кнопка не залипает после успеха, правила полей (email необязателен, но «test@» не пропускается; имя до 50 символов), закрытие крестиком/фоном/Esc, фокус и Tab. Серверная часть формы (`mail.php`, с заглушками вместо почты и Google): все ответы, письмо не ушло → ошибка, лимит считает только ушедшие заявки. Меню шапки в обоих режимах и при смене режима, бургер, аккордеон подвала, увеличение фото в статьях, все видео закрываются и останавливаются, счётчики главной считают один раз, каталог работ, каталог сувениров (сортировки, «По умолчанию», «Назад», поиск, «Ничего не найдено», сборка PDF), соцсети, архив фото по паролю (верный/неверный).

## Проверить на своём компьютере (`npm run dev`)

### 1. Форма заявки — главное

- [ ] `index.html` → «Сделать заказ»: форма открылась, через 1–2 с появилась галочка «Я не робот». Вокруг самой формы нет рамки фокуса, вид как раньше.
- [ ] F12 → **Network**, в фильтре `recaptcha`, обновить страницу: до открытия формы запросов нет, после открытия — появились.
- [ ] Поле email подписано «Ваш email (необязательно)».
- [ ] Заполнить имя и телефон, email оставить пустым, галочку не ставить → «Отправить» → красная надпись «Поставьте галочку «Я не робот»» (то есть пустой email пропущен).
- [ ] Email «test@» → «Отправить» → подсказка «Введите правильный Email».
- [ ] Имя «Константинопольская Александра» проходит без подсказки.
- [ ] Понажимать **Tab** — фокус ходит по полям, галочке, ссылке и кнопке по кругу, на страницу под формой не уходит. **Esc** закрывает форму, фокус возвращается на кнопку, которой её открыли.
- [ ] Набрать комментарий, закрыть форму кликом по фону, открыть снова — комментарий на месте.
- [ ] **Баннер рекламы** на главной: заголовок формы «Заказать рекламу»; закрыть, открыть «Сделать заказ» — снова «Рассчитать стоимость» и полный текст с фразой про персонального менеджера.
- [ ] `news59.html`: телефон набирается по маске `+7 (___) ___-__-__`; «Отправить» с пустыми полями подсвечивает ошибки.

## После деплоя — на живом сайте `lazurprint.ru`

### 10. Тестовая заявка — обязательно, делаете сами

- [ ] Открыть, например, `lazurprint.ru/how-to-order.html` → «Рассчитать стоимость» → имя, телефон, **email не заполнять**, комментарий «тест, не обрабатывать» → галочка «Я не робот» → «Отправить». Открылась страница «Ваше письмо отправлено», письмо пришло менеджерам, в нём «Почта: не указана».
- [ ] Вторая тестовая заявка — **с email**. В письме «Ответить» подставляет адрес клиента.
- [ ] На странице «спасибо» нажать «Назад» — кнопка «Отправить» в форме не серая.
- [ ] **Если письмо пришло, а форма показала «Не удалось отправить заявку»** — хостинг дописывает в ответ предупреждения PHP: в Console будет строка «неожиданный ответ mail.php» — прислать её. Если под формой любая другая красная надпись — прислать её текст.
- [ ] Архив фото на `lazurprint.ru/events.html` открывается верным паролем (на живом сайте — по https).

### 11. Счётчики — через день после деплоя

- [ ] Яндекс.Метрика: посещаемость не упала (код не менялся, только переехал в общий файл).
